# Owned simple-sequence ItemAt Project corpus

This finite corpus qualifies the explicit `_with_basic_owned_sequence_item_at`
profile, composing qualified By/filter/sort/windows/primary-row failures. It is
not a general generated-item or observer permission. Genuine public Projects,
typed source trees and complete expected results/errors are authored without
executing any producer, selecting from a generated vector, lowering, emitting,
or observing an implementation result as an oracle.

Only Generate (omitted/explicit from), Tokenize, TokenizeByLength and
TokenizeRegex (absent/present flags) are positive producers. Parent scalar
producer arguments and the index retain actual source owners, frame pins and
positions; nested eligible ItemAt creates no generated source frame. Each
synthetic item declaration remains SourceField([], frame=None).

## Independent expectations

The data distinguishes Primary.Cfg, exact Named("Cfg"), exact Named(" Cfg💠 ")
and a separate legacy binding. Complete ordered Group/Repeated trees retain
every scalar tag, Float bit and XML-origin fact. Output unions avoid accidental
Int-to-String/Float target coercion; a separate Float-target case exercises the
existing target adapter intentionally. Nonfinite inputs use exact bits, never
ordinary Instance JSON serialization.

Index Float conversion rounds ties away from zero, unlike ByLength width's
finite truncation and integer-string parsing. Unicode chunks count scalars,
not UTF16 units or grapheme clusters. Literal splitting preserves empty items;
regex splitting validates first and returns no items for empty text. Parent
null/JsonNull suppression stops later producer arguments but never skips an
index after successful production. XmlNil is not producer null suppression.

Error frontiers distinguish producer and index exceptions, full-materialization
limits before invalid indexes, unavailable versus present-but-absent owners,
inactive foreign frames, malformed traversal and repeated terminals. Global
failure rules precede every target selection's producer/index work. Grouped
cases distinguish representative, group ordinal, member and immutable-root
reads; cross-owner nesting retains outer pins.

All/Primary/exact named selection expectations are complete, not summaries.
Every catalogue keeps original declaration ordinals: owned-only reads Optional,
potential legacy aliases RequiredLegacy even on an inactive branch, and unused
dynamic slots ReservedUnavailable. Ordinary saved-project ItemAt serialization,
pretty-plus-LF output and same-API historical artifact preservation are separate
controls. The complete ordinary artifact expectations and exact portable manifest
template are documented in [legacy-baseline](legacy-baseline/README.md).
Older lower/validate/admission/emitter families must retain their old refusal.

## Boundaries and evidence protocol

Project counts/calls are derived from the authored case list and literal profile
inventory. Static lowering controls, API gates, legacy serialization controls
and synthetic harness checks are not counted as extra multi-engine cases.

The Project corpus does not prove exact callback counts merely because values
match. `edge-observations.json` freezes independent expectations for existing
internal component facilities; no new public observer or snapshot domain is
qualified. FilterMap's isolated stages/captures and full RecursiveCollect,
function, join, document/XML, dynamic, specialized-construction and closed
SequenceExists/SequenceAggregate families require component coverage. ItemAt
does not open those contexts, including inactive branches/default/message
edges or failure predicates/messages. No direct-Program structural coverage is
claimed by genuine Project lowering checks.

The mandatory five owned limits bound metadata/context work, not vector
payload, allocator/RSS or CPU. Existing pure-sequence/regex limits remain in
force. Paired resource/witness/UTF8 boundary tests remain component work.

Preparation is compiler- and native-execution-free. It retains complete public
Projects, independent controls, typed diagnostic results, both artifact sets,
callers and source/runtime/command bindings. Qualification is a separate ignored
stage requiring fresh successful unchanged preparation and a serialized lane
grant. All engines retain complete lossless raw output trees plus typed causes
before closed normalization/comparison; Debug alone is insufficient. Observer
failures are failed calls and do not suppress later calls/engines. Required
evidence I/O errors remain concrete failures. Every originally bound file is
rehashed after execution; missing/modified originals fail, while added build
and evidence files are allowed. Never alter an expected recipe to fit an actual.

Each command uses the maintained `host_policy::recorded_output_with_sources`
with relative source roots for that consumer and its controls/success binding.
Command retention never recursively copies earlier actuals or other campaigns.
The complete prepared-campaign original-file fence remains independent and
unchanged. Fresh C# bin trees are hashed before and after DLL execution, and
binary identity participates in host success; source snapshots alone do not
identify a tested executable.
