# Owned By grouping genuine-Project corpus

This finite corpus qualifies #441 through #819; it is not a vendor-conformance
or full-product/resource-parity claim. `projects.rs` constructs genuine public
Projects. `cases.rs` fixes inputs and complete ordered typed output/error
recipes independently of lowering, native evaluation and generated execution.
Helpers render explicitly listed members; none computes expected buckets by
grouping the input. All output names, scalar tags, Float bits, ordered fields
and exact Group XML-origin metadata are compared. Authored Groups have Unknown
origin; they are not silently equated with Absent or an explicit origin.

## Inventory and contracts

The execution inventory is **59 cases / 169 calls per engine**, using 45
Project profiles. Calls cover All, Primary and exact named target ` audit💠 `;
root/scalar-only profiles have two calls and two selection-only controls have
one. Ten additional genuine-Project controls freeze complete typed lowering
diagnostics: four other grouping modes, aggregate/lookup/find under grouped
owned ancestry, malformed post/conflicting controls and an exact unknown owner.
Old emitters are checked separately for their unchanged typed Grouping refusal.
All 45 profiles also have independently fixed complete All/Primary/named input
catalogues, including declaration ordinals and Optional/RequiredLegacy modes.
The legacy RequiredLegacy target does not make its input eager for Primary or
the owned audit target; the Alias repeated-root selector does require Alias.
`legacy-project.json` is an ordinary saved-project control without owned fields;
its round trip and ordinary behavior/pretty-plus-LF serialization remain separate.
The ordinary legacy saved-project adds two calls per engine, giving 171
execution calls per engine when that compatibility control is included.

`Rows` names both Primary's collection and an independent declared source.
The other exact owner ` Røws💠 ` includes significant spaces and Unicode.
Labels/markers differ across P, N and U. Primary input rows are, in raw order:
`A/P-a1/false/30`, `B/P-b1/true/10`, `A/P-a2/true/20`,
`C/P-c1/false/40`, `B/P-b2/false/15`. N has independent Keep values
false/false/true/false/true and ranks 300/100/200/400/150.

## Coverage boundaries and evidence

The new emitter profile is explicitly `_with_basic_owned_group_by`, composing
the already-qualified primary-row-failure permission. Generated typed entry
names stay `execute_with_basic_owned_sources` / selected and C# equivalents,
with a mandatory five-field caller policy. There is no new JSON adapter API.
Other grouping modes, joins/generated/document/dynamic/function/specialized
consumers, grouped owned observers and all older profile gates stay closed.
The component-native/common/backend suites must qualify those remaining closed
consumer families; this corpus does not replace their specialized constructions.

Authentic/wrong-registry/duplicate/empty witness controls, cumulative group/key/
path accounting, W/F/P and UTF8 boundaries, exact/overflow/representability
checks, and grouped observer closure belong to the paired runtime/native
component suites. Project successes cannot establish those resource contracts.
Do not invent new numeric MetadataSlots envelopes from this dataset. The five
owned limits are metadata/context limits, not source/output payload, allocator,
RSS or CPU guarantees.

The CLI test module uses existing host_policy, exact source/artifact hashes,
separate compiler-free preparation and serialized consumers. Full authored
Projects, tagged inputs/expected outcomes, validation/lowering/emission results,
raw errors/complete typed causes, source bindings and every command are retained
before comparisons. Failed originals are never removed or turned into a
successful preparation. Corrections require independent source/contract evidence
and preserving the prior authored version outside the deliverable corpus.

Raw public products are retained before closed normalization or comparison.
Native and generated Rust/C# raw captures include every current Instance kind,
document paths, complete scalar bits and XML metadata even when the corpus codec
rejects the kind. Debug and typed-cause logs supplement, not replace, raw trees.
Observation failures are recorded as failed calls and do not suppress later
calls or engines; required evidence I/O remains a typed failure. Harness-only
unexpected-kind/continuation controls do not change the mapping-call inventory.
After execution every original success-manifest evidence file is checked again
by its original length and SHA256, including controls and callers. Additional
build/output files are allowed; changed or missing original files are not.
