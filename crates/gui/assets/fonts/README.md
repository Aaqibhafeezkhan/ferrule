# Bundled CJK fallback font

`NotoSansCJKsc-Regular.otf` is the unmodified regular Simplified Chinese face
from Noto Sans CJK version 2.004. It supplies missing Han, Kana and Hangul glyphs
after the existing proportional and monospace fonts. Han glyph forms follow the
SC face; this is not locale-specific font selection or universal Unicode coverage.
